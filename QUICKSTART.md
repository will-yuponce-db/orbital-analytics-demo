# 🚀 Quick Start Guide

## Development Server

For development with hot module reloading:

```bash
npm run dev
```

Runs on **http://localhost:5173**

## Production Server

Run the production-optimized application:

```bash
npm start
```

This command will:
1. ✅ Type-check your TypeScript code
2. ✅ Build the optimized production bundle
3. ✅ Start the production server on **http://localhost:4173**

---

**Ready to launch!** 🛰️ Just run `npm run dev` for development or `npm start` for production
